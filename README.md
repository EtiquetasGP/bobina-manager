# Bobina Manager

Crea una aplicación web simple llamada Gestión de Bobinas (CQ)
Por ahora crea únicamente una pantalla inicial básica con ese título.
No crees bases de datos, tablas, funciones ni backend. No uses Lovable Cloud.
El backend existente de Supabase se conectará después.

This project was built with [Lovable](https://lovable.dev).
